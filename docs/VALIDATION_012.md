# PS2 Studio 0.12 validation matrix

## Automated
- project structure and metadata
- PS2DEV / PS2SDK / GSKIT environment
- EE / IOP / DVP executable discovery
- PCSX2 and ps2client discovery
- ISO authoring tool discovery
- Debug / Optimized / Release build pass

## Manual
- Game View behavior against PCSX2 behavior
- controller mapping and audio output
- real PS2 ps2link/ps2client deployment
- VU1 path behavior versus EE fallback
- burned-disc read-back verification
- real-console boot on the user's legitimate homebrew-capable test setup

The IDE does not implement a retail-console security bypass.
